# ElasticDino 3 32-S

This DINOv3 ViT-S/16-plus model produces a 256 × 256 dense feature map. The [DINOv3 backbone](https://huggingface.co/facebook/dinov3-vits16plus-pretrain-lvd1689m) is gated; accept Meta's access terms and authenticate with Hugging Face. See the [project README](https://github.com/odusseys/ElasticDino#readme) for installation and usage.
